## Описание
Task Planner — это веб-приложение для управления проектами и задачами, предназначенное для личного использования и совместной работы команд. Модуль поддерживает функционал канбан-досок, распределение ролей, отслеживание дедлайнов и визуализацию статистики через интерактивные дашборды.

## Технологии
- PHP 8.0
- MySQL
- Bootstrap / Tailwind CSS

## Установка и запуск
1. Клонируйте репозиторий:
   ```
   git clone https://github.com/terminator359874/zhakanoov-pr35-planer.git
   ```
2. Скопируйте папку в OpenServer/domains/
3. Создайте базу данных и импортируйте database.sql
4. Настройте config/db.php
5. Откройте http://localhost/planer/
