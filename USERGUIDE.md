# Руководство пользователя — Task Planer
## Вход в систему
1. Откройте браузер
2. Введите адрес: http://localhost/planer/
3. Введите логин и пароль
4. Нажмите «Войти»

## Основные функции

### 1. Создание проекта
Проекты позволяют группировать задачи по направлениям (например, «Ремонт», «Маркетинг», «Разработка сайта»).

* На главной панели управления нажмите кнопку **«+ Новый проект»**.
* В появившемся окне введите название проекта и краткое описание.
* Нажмите **«Сохранить»**. Новый проект появится в вашем списке в левой части экрана.

### 2. Создание задачи
Задачи — это конкретные действия, которые необходимо выполнить внутри проекта.

* Выберите нужный проект из списка.
* Нажмите кнопку **«Добавить задачу»** (обычно находится в верхней части колонки задач).
* Заполните детали:
    * **Название:** Кратко сформулируйте суть дела.
    * **Описание:** Добавьте подробности или инструкции.
    * **Срок:** Укажите дату завершения.
    * **Приоритет:** Выберите уровень важности (Низкий, Средний, Высокий).
* Нажмите **«Создать»**.

### 3. Изменение статуса задачи
Статусы помогают отслеживать прогресс выполнения работ.

* Найдите нужную задачу в списке проекта.
* Вы можете изменить статус двумя способами:
    1.  **Перетаскивание (Drag-and-Drop):** Просто зажмите задачу мышкой и перетащите её в нужную колонку (например, из «В планах» в «В работе» или «Готово»).
    2.  **Меню задачи:** Нажмите на иконку карандаша или текущий статус внутри карточки задачи и выберите новый вариант из выпадающего списка.
* Система автоматически сохранит изменения и уведомит участников проекта (если это настроено).

## Полезные советы
* **Поиск:** Используйте строку поиска в верхней части экрана, чтобы быстро найти задачу по названию.
* **Фильтры:** Вы можете отфильтровать задачи по исполнителям или срокам, чтобы сфокусироваться на самом важном
